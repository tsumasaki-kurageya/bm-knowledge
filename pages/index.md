# 建物維持保全の業務ガイド

建物を安全・衛生的に使い続けるために、どんな仕事があり、誰が関わり、次に何をするのかを説明します。所有者・管理者・現場の作業者など、建物に関わる人たちの仕事を扱います。

## はじめて読む方へ

1. [建物維持保全の全体像（BUSINESS-001）](00-business/overview.md)で、仕事の目的を知る。
2. [業務の分類（DOMAIN-000）](01-domains/overview.md)で、9つの仕事のまとまりを見る。
3. [業務フロー一覧（PROCESS-001）](02-processes/overview.md)から、知りたい仕事の手順を読む。

## 知りたいことから探す

| 知りたいこと | 読むページ |
| --- | --- |
| 誰が作業し、誰が判断するのか | [関わる人と建物ごとの違い（BUSINESS-002）](00-business/actors.md) |
| 点検や修繕が、次の仕事にどうつながるのか | [業務のつながり（PROCESS-024）](02-processes/lifecycle.md) |
| 毎日の仕事と、数年先の計画はどう関係するのか | [日々の仕事と将来の計画（BUSINESS-003）](00-business/value-stream.md) |
| 説明の根拠を確かめたい | [参考資料と使える範囲（BUSINESS-004）](00-business/sources.md) |

メニューの「業務の分類」は各分類の説明、「業務フロー」は同じ9分類にまとめた個別の仕事です。仕事の名前で検索することもできます。

このガイドは公開資料をもとにしています。建物ごとの担当・契約・法令の条件は、各ページの「情報源」「未確認事項」で確かめてください。
