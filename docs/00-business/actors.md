# 関わる人と建物ごとの違い

建物の維持保全には、依頼する人、作業する人、結果を確認する人、費用や実施を承認する人が関わります。誰がどの役割を持つかを確認します。

## 誰が何を判断するか

PM（プロパティマネジメント）やFM（ファシリティマネジメント）という名称だけでは、委託範囲や決裁権限は分かりません。このガイドでは、組織名より「何を依頼・判断・実施するか」で役割を確かめます。管理権原とは、その建物や部分を管理する権利・権限のことです。

下表は [S3](sources.md#s3-保全担当者向けの体制台帳計画)、[S5](sources.md#s5-建築物環境衛生管理技術者の職務)、[S7](sources.md#s7-維持保全計画に関する指針) を手がかりにした分析上の役割整理です。組織名だけで責任は決まりません。同一の組織が複数の役割を兼ねる場合もあります。

| 主体の例 | 想定する役割 | 個別に確かめること |
| --- | --- | --- |
| 所有者・管理組合 | 利用方針、費用負担、修繕・更新への意思決定 | 決裁権限、共用・専有の範囲、合意形成手続 |
| 利用者・テナント・占有者 | 必要な利用条件の提示、異常の通報、使用制限への協力 | 利用時間、作業への立会い、設備や部分の管理権原 |
| 運営者・管理者・PM / FM担当 | 要求整理、計画・予算調整、委託管理、情報の集約 | 契約上の業務範囲、緊急対応権限、発注・承認の権限 |
| ビルメンテナンス会社・専門工事会社・点検会社 | 受託範囲の作業、状態の報告、技術的提案 | 資格要件、報告先、是正工事を含むか、完了確認者 |
| 法令等に基づく選任技術者 | 対象分野の監督・評価・意見提示 | 選任根拠と職務範囲。施工担当や予算承認者と同一視しない |
| 設計者・メーカー等 | 仕様・技術情報の提供、原因調査や対策検討への支援 | 保証・保守契約、図書、部品供給や更新条件 |
| 行政・所管機関等 | 所管制度に基づく確認・指導等 | どの制度・権限に基づく関与か。日常管理の実施者とは区別する |

技術者の具体例として、厚生労働省は建築物環境衛生管理技術者の職務に、計画立案、指揮監督、測定・検査結果の評価等を挙げています。[S5](sources.md#s5-建築物環境衛生管理技術者の職務) この役割をすべての保全分野にそのまま拡張しません。

## 顧客と周辺の関係者を確かめる

顧客の業務を理解するときは、「要求・依頼」「計画・調整」「実施」「技術的確認」「費用・実施承認」の担当を確かめます。実施者が報告書を提出しただけで、発注者の受入や状態の回復が完了したとみなさない整理です。

引継ぎでは、対象部位、現状、残る問題、実施済み対策、次に判断する人を記録対象とします。これは [S3](sources.md#s3-保全担当者向けの体制台帳計画) の履歴管理、[S7](sources.md#s7-維持保全計画に関する指針) の責任範囲を踏まえた提案であり、現場での実施事実ではありません。

SaaSを使う人、作業を依頼する人、費用を負担する人、結果を利用する人が誰かを確かめます。同じ会社でも別の担当者が担う場合があります。顧客が困っている仕事の前後にいる相手まで確認すると、誰の判断や情報が必要かを整理できます。

## 用途・所有・運営による違い

| 条件 | 変化する要求・実施条件 | 根拠と確度 |
| --- | --- | --- |
| 建築物衛生法の特定建築物への該当 | 衛生管理基準に従う維持管理。非該当でも多数が使用・利用する建築物には努力義務の説明がある | [S2](sources.md#s2-建築物環境衛生管理基準) に記載。該当判定は個別確認 |
| 国家機関の建築物 | 施設保全責任者、台帳、中長期・年度計画という管理の枠組み | [S3](sources.md#s3-保全担当者向けの体制台帳計画) の対象範囲内 |
| 区分所有マンション | 共用部分の修繕、費用の積立、区分所有者間の合意形成 | [S4](sources.md#s4-長期修繕計画の考え方)。建物の管理区分等を個別確認 |
| 複数の管理権限者・複合用途 | 部分ごとの責任範囲と計画の整合を確認する必要 | [S7](sources.md#s7-維持保全計画に関する指針) は複数の計画作成権限者を想定 |
| 単独所有・自社利用と賃貸運営 | 要求者・費用負担者・承認者が同じか分かれるかを確認 | 分析上の確認観点。具体的な責任分界は契約等が未確認 |
| 常駐・巡回・遠隔管理、夜間利用 | 発見経路、連絡方法、初動までの条件が変わる | 分析上の仮説。実際の時間・人数は現場の記録で検証 |
| 24時間稼働、医療・生産等の用途 | 計画停止の可否、復旧の優先順位、代替手段を確認 | 用途別の要求水準は未確認。特定用途の無停止義務とは断定しない |
