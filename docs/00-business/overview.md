# 建物維持保全の全体像

## 目的と対象範囲

建物維持保全とは、建物を安全・衛生的に使い続けるために、状態を調べ、手入れし、必要に応じて直すことです。将来の修繕や設備交換に向けた計画、費用の準備も含みます。

このガイドでは、日本の既存の建物・敷地・設備を対象に、所有者・管理者・作業者などの仕事を整理しています。特定の会社の担当範囲に限りません。新築事業、物件売買、賃貸営業そのものは対象外です。建物の使い方や所有者の方針が、管理や予算に与える影響は扱います。

ここでの説明は複数の公開資料をもとにしたもので、法令上の用語の定義ではありません。

## 顧客が目指す結果を理解する

顧客の担当する作業を、建物の利用や所有者の判断につなげて読みます。例えば点検の記録を作ることと、指摘した不具合への対応が決まることは、別の結果です。SaaSがどの仕事を支援するか考える際は、作業の手間と、その先で達成したい状態を両方確かめます。

下の表は業務の目的から整理したリスクと価値で、特定の顧客で確認した課題の一覧ではありません。

## 何を守るために、どんな仕事をするか

| 観点 | 防ぎたい問題 | 目指す状態 |
| --- | --- | --- |
| 人の安全 | 部材の落下、転倒、防火・避難機能の支障 | 通常利用と非常時の安全機能を保つ |
| 衛生・利用環境 | 空気や水の汚染、汚れ・害虫、不適切な室内環境 | 健康に配慮した衛生的な環境を維持する |
| 機能継続 | 設備不調や漏水により建物内の活動に支障が出る | 必要な機能を利用でき、不具合時に回復できる |
| 法令等への適合 | 必要な維持管理が漏れ、適合状態を維持できない | 対象に適用される要求を把握し、履行・確認できる |
| 資産保全 | 劣化を放置し、性能や利用可能性が低下する | 必要な性能を維持・回復し、長く利用できる |
| 経済性・実行可能性 | 修繕時期や費用が見通せず、必要な工事に資金が不足する | 必要な対策と費用を見通し、資金と実施条件を整える |
| 管理の継続性 | 履歴や責任範囲が不明で、判断・対応が途切れる | 状態と判断理由を共有し、引継ぎ後も対応できる |

### 仕事と、その結果が役立つ相手

| 観点・仕事の例 | 誰にどう役立つか | 根拠 |
| --- | --- | --- |
| 人の安全：状態確認、危険箇所の使用制限、補修、機能の再確認 | 利用者・周辺の人の被害を防ぐ | [S1](sources.md#s1-支障がない状態の確認)、[S7](sources.md#s7-維持保全計画に関する指針) |
| 衛生・利用環境：空気・水の測定、設備調整、清掃、防除、結果評価 | 利用者が衛生的な環境で活動できる | [S2](sources.md#s2-建築物環境衛生管理基準) |
| 機能継続：点検、異常把握、影響判断、修理、復旧確認 | 利用者・運営者の活動を支える | [S1](sources.md#s1-支障がない状態の確認) |
| 法令等への適合：適用条件の確認、計画、実施体制・記録の整備 | 所有者・管理権原者が管理の根拠を説明できる | [S2](sources.md#s2-建築物環境衛生管理基準)、[S6](sources.md#s6-維持保全計画の意義)、[S7](sources.md#s7-維持保全計画に関する指針) |
| 資産保全：劣化調査、修繕・更新の計画と実施 | 所有者・将来の利用者が建物を使い続けられる | [S4](sources.md#s4-長期修繕計画の考え方)、[S6](sources.md#s6-維持保全計画の意義) |
| 経済性・実行可能性：概算費用・時期の検討、資金計画、合意形成、見直し | 費用負担者が将来負担を判断しやすくなる | [S4](sources.md#s4-長期修繕計画の考え方)、[S7](sources.md#s7-維持保全計画に関する指針) |
| 管理の継続性：台帳・図書の保管、役割の明確化、結果の報告 | 所有者・管理者・受託者が共通の情報で判断できる | [S3](sources.md#s3-保全担当者向けの体制台帳計画)、[S7](sources.md#s7-維持保全計画に関する指針) |

活動例は業務領域の確定一覧ではありません。機能停止が事業へ与える具体的な影響、停止許容時間、必要な冗長性は建物ごとの判断事項です。維持保全だけで無停止や市場価格の維持を保証するものではありません。

## 要求・目的・成果を区別する

- **問題**：現在生じている、または将来生じ得る不都合。
- **要求**：法令、所有者・利用者の利用目的、合意した管理条件から求められる状態。
- **目的**：その要求を満たすため、維持保全として実現する状態。
- **活動**：目的へ近づけるために実施する仕事。
- **成果**：実施後に状態が改善・維持されたこと。報告書の作成は成果を確認するための記録でもある。

例えば「点検を終えた」と「支障が解消した」は別です。国土交通省の官庁施設向け資料は、確認で支障を把握した場合の保全を求めています。[S1](sources.md#s1-支障がない状態の確認) 本整理では、実施記録に加えて状態の評価までを活動のつながりに含めます。

## 要求の優先順位と適用

法的要求、契約上の要求、任意の改善目標は区別して記録します。法定要求の適用は、用途・規模・設備・管理権原などで確認します。官庁施設の要領やマンションの修繕積立方式を、民間建物すべての義務とは扱いません。

安全性や必要性能と費用・停止時間には調整が必要です。本整理では「適用される義務と重大な危険への対応を確認し、その上で複数案の費用・時期・利用への影響を比較する」を判断の観点とします。予防的な交換が常に最安であるとは仮定しません。

具体的な適用条件は [関わる人と建物ごとの違い（BUSINESS-002）](actors.md)、活動の循環は [日々の仕事と将来の計画（BUSINESS-003）](value-stream.md) を参照してください。

## 未確認事項

- 病院・工場・宿泊施設など、用途固有の継続要求・衛生要求を補う一次資料。
- 各建物に適用する法令・条例・契約と、その義務者・周期・報告先。法令で必要な業務の一覧は未確定。
- エネルギー・水・廃棄物など環境負荷の要求を、経済性や衛生とどう区別して位置付けるか。
- 標準規格における保全・維持管理・FMの定義との対応。未読の規格本文に準拠したとは扱わない。
- 一般化した整理と実際の現場の差。現場の記録を収集した後に検証する。
