# 守るルールと利用条件を確認する

## 目的

建物に適用される法令・契約や、利用者が必要とする条件を確認し、計画や作業の前提をそろえます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-001：守るルール・利用条件](../01-domains/requirements.md)
- 関連領域：[DOMAIN-002：作業・修繕・費用の計画](../01-domains/planning.md)、[DOMAIN-003：担当・発注・作業の調整](../01-domains/delivery-coordination.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

管理開始、用途・設備・契約・利用要求の変更、要求の定期見直し。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：適用判定の対象。
- 契約：合意事項を法的義務と区別。
- 運用：任意の利用目標も別に記録。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 管理者・専門家 | 要求整理・適用確認 | 条件の収集と適用確認 |
| 所有者・権原者 | 方針判断 | 要求・責任の確認と方針判断 |
| 利用者 | 利用条件の提示 | 利用条件の提示 |

<a id="入力"></a>

## 必要な情報

- 建物・設備概要
- 所有・管理権原
- 法令・条例・契約の候補
- 利用要求

## 標準フロー

概略のつながりのみを示す。建物・契約・利用の条件を整理し、適用根拠と確認できない条件を分けて、要求を関係者へ共有する。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

将来の工事内容・予算の決定は計画へ渡す。全用途の法定業務を一律に決めない。

<a id="出力"></a>

## 作業後に残すもの

- 適用根拠・対象・義務者を区別した要求一覧
- 確認できない条件・照会先
- 変更事項

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：管理開始、用途・設備・契約・利用要求の変更、要求の定期見直し。 前工程の完了だけが開始条件ではない。
- 変更・事象起点：対象の変更や新たな事象ごとに開始する。固定の実施周期を仮定しない。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
