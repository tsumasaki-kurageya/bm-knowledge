# 結果を報告し、未対応のものを確認する

## 目的

作業結果を必要な相手へ伝え、まだ対応していない指摘について、次の担当者や対応状況を確認します。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-009：記録・報告・改善](../01-domains/records-evaluation.md)
- 関連領域：[DOMAIN-001：守るルール・利用条件](../01-domains/requirements.md)、[DOMAIN-003：担当・発注・作業の調整](../01-domains/delivery-coordination.md)、[DOMAIN-005：点検・測定](../01-domains/inspection-assessment.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

報告・提出時期、作業・点検完了、重要異常、指摘への回答期限。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：法定報告・届出は該当条件を確認。
- 契約：月次等の報告条件。
- 運用：任意の共有と未対応追跡を区別。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 報告作成者 | 報告作成 | 内容の整理 |
| 管理者・提出責任者 | 提出・追跡の調整 | 確認と提出調整 |
| 報告先・対応者 | 受領・対応結果の共有 | 受領・指摘・対応結果の共有 |

<a id="入力"></a>

## 必要な情報

- 要求・提出条件
- 実施・評価結果
- 未対応一覧
- 受領・指摘情報

## 標準フロー

概略のつながりのみを示す。要求に応じて報告を確認・提出し、受領・指摘・対応状況を追跡して、完了根拠または残課題を残す。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

提出したことと支障が解消したことを同一視しない。報告先が常に行政とは限らない。

<a id="出力"></a>

## 作業後に残すもの

- 提出・共有した報告
- 受領状況
- 対応先・期限・完了根拠を持つ残課題

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：報告・提出時期、作業・点検完了、重要異常、指摘への回答期限。 前工程の完了だけが開始条件ではない。
- 繰返し：次の合意済み実施時期・評価時期等で本業務を再開する。毎回同じ計画・発注・承認をやり直すとは限らず、条件変更がある場合に見直す。周期・期限は法令・契約・管理計画で確認する。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
