# 給排水の衛生維持・害虫防除

## 目的

水・排水・害虫等に関わる衛生上の支障を抑える。

[PROCESS-001：業務カタログ](overview.md)に属する概略文書。目的・入出力・役割・前後関係は、記載した情報源の構成要素を本知識ベースで業務単位にまとめた整理案であり、現場で確認した実態や一律の法定手順ではない。

## 対象業務領域

- 主領域：[DOMAIN-004：運用・維持作業](../01-domains/operations.md)
- 関連領域：[DOMAIN-005：点検・測定・状態評価](../01-domains/inspection-assessment.md)

主領域は主な成果の置き場所。関連領域ごとに別のProcessを重複作成しない。

## 開始条件

予定した衛生作業、測定・調査による対策要請、衛生異常。

## 業務の性質・適用条件

- 法令：建物・設備の適用条件による。
- 契約：衛生作業の範囲。
- 運用：調査結果に基づく日常・定期・臨時の対応。

「法令・契約・運用」は排他的ではない。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

主体は役割の例。同じ主体の兼務や複数主体での分担があり、最終的な責任・決裁権限は法令・契約・管理条件で確認する。

| 主体 | 役割 | 責任・判断 |
| --- | --- | --- |
| 衛生管理担当者・専門業者 | 衛生対策の実施 | 対象別の対策 |
| 管理者・専門的監督者 | 結果確認・判断 | 結果確認と追加対応判断 |
| 利用者 | 利用調整への協力 | 利用制限等への協力 |

## 入力

- 設備・衛生条件
- 水質等の結果
- 生息・発生状況
- 作業条件

## 標準フロー

概略のつながりのみを示す。衛生上の問題と対象を整理し、必要な対策を実施して、測定・調査等の効果確認へつなぐ。

詳細な手順・分岐・例外は後続Issueで整理する。

## 分岐・例外

水の衛生維持と防除を現時点ではまとめる。測定・調査と、状態を変える対策は分ける。

## 出力

- 衛生対策の結果
- 効果確認に必要な情報
- 残る異常・設備対策の要請
