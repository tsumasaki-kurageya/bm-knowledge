<a id="給排水の衛生維持害虫防除"></a>

# 水まわりを衛生的に保ち、害虫を防ぐ

## 目的

給水・排水の衛生を保ち、ねずみや害虫による問題を防ぎます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-004：日々の運転・手入れ・清掃](../01-domains/operations.md)
- 関連領域：[DOMAIN-005：点検・測定](../01-domains/inspection-assessment.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

予定した衛生作業、測定・調査による対策要請、衛生異常。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：建物・設備の適用条件による。
- 契約：衛生作業の範囲。
- 運用：調査結果に基づく日常・定期・臨時の対応。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 衛生管理担当者・専門業者 | 衛生対策の実施 | 対象別の対策 |
| 管理者・専門的監督者 | 結果確認・判断 | 結果確認と追加対応判断 |
| 利用者 | 利用調整への協力 | 利用制限等への協力 |

<a id="入力"></a>

## 必要な情報

- 設備・衛生条件
- 水質等の結果
- 生息・発生状況
- 作業条件

## 標準フロー

概略のつながりのみを示す。衛生上の問題と対象を整理し、必要な対策を実施して、測定・調査等の効果確認へつなぐ。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

水の衛生維持と防除を現時点ではまとめる。測定・調査と、状態を変える対策は分ける。

## 作業後に残すもの

- 衛生対策の結果
- 効果確認に必要な情報
- 残る異常・設備対策の要請
