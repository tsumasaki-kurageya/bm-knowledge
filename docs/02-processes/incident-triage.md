# 異常の連絡を受け、影響を判断する

## 目的

異常の連絡を受け、何が起きたか、どこまで影響があるか、急ぐ必要があるかを整理して次の担当者につなぎます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="詳細化の範囲"></a>

## このページで扱う範囲

官庁施設向け保全委託の、運転・点検等で異常を認めた場合の連絡を具体例とする。利用者の申告も入口に含むが、受付フォーム、緊急度の等級、応答時間、原因診断の必須順序は原典から確定できない。

手順は資料をもとに読みやすく整理したものです。資料に書かれた内容と、確認が必要な点を根拠欄で区別しています。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-006：異常・故障への対応](../01-domains/incident-response.md)
- 関連領域：[DOMAIN-004：日々の運転・手入れ・清掃](../01-domains/operations.md)、[DOMAIN-005：点検・測定](../01-domains/inspection-assessment.md)、[DOMAIN-008：事故の予防・災害への備え](../01-domains/risk-preparedness.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

利用者の申告、警報、点検指摘、巡回・作業での異常発見。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：必要な通報・措置は事象別確認。
- 契約：受付・対応範囲。
- 運用：非緊急の不具合も含む。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

<a id="終了条件"></a>

## どこまでできれば完了か

異常について判明した内容と不明点、引渡し先・対応判断を区別して記録できることを本書の終了条件とする。受付を終えたことは、復旧・危険解消・利用再開の完了ではない。引渡しを確認できなければ、その事実を未確認として残す。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 発見者・受付者 | 受付・情報整理 | 事実の連絡と整理 |
| 管理者・権限者 | 優先度判断 | 優先度・連絡先の判断 |
| 専門家 | 専門的評価 | 影響評価の支援 |

<a id="入力"></a>

## 必要な情報

- 場所・時刻・症状
- 影響範囲
- 既知の状態
- 連絡・権限条件

## 判断ポイント・分岐

| 判断すること | 分岐・扱い | 根拠または確認条件 |
| --- | --- | --- |
| 緊急性がある・否定できない | 連絡や必要な対応を、受付項目が全て埋まるまで待たせるモデルにしない。 | F1第3編1.1.12〜13／不明時の指揮系統は個別確認 |
| 原因が分からない | 症状と原因の推定を分ける。故障原因を確定せず専門判断へ渡す。 | 本書の記録上の整理／追加調査の手配方法は未確認 |
| 非緊急で工事の検討が必要 | 既存のPROCESS-017への引渡しを使う。緊急性が変われば対応判断を見直す。 | 既存の遷移条件／計画対応へ移せる基準は未確認 |

## 分岐・例外

| 代表的な例外 | 扱い | 根拠または未確認 |
| --- | --- | --- |
| 連絡先不在・応答なし | 事前体制の代替先を確認する。独自のエスカレーション時間・順番を追加しない。 | F1第3編1.1.13／代替先・期限は未確認 |
| 複数申告が同時に届く | 同じ事象か確認できないまま統合・削除しない。 | 未確認：重複判定・優先順位・受付単位 |
| 契約対象外の異常 | 対象範囲と確認した異常を分け、情報の連絡と有償対応の判断を混同しない。 | F1第3編1.1.5(b)／契約外作業の手配は未確認 |

## 使用される情報・帳票

既存の入出力を具体化する。資料の様式を全建物の必須帳票にせず、保存可能な記録の内容と役割を示す。

| 情報・帳票 | 使用目的 | 根拠・適用条件 |
| --- | --- | --- |
| 異常の連絡情報 | 場所・症状・発生状況など分かった内容を渡す | 既存入力を具体化。必須項目・専用様式は未確認 |
| 連絡体制・対応条件 | 連絡先・判断者を確認 | F1第3編1.1.13 |
| 日誌・協議記録 | 判明した経過を保存 | F1第3編1.1.11、第1編1.2.4 |

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：利用者の申告、警報、点検指摘、巡回・作業での異常発見。 前工程の完了だけが開始条件ではない。
- 変更・事象起点：対象の変更や新たな事象ごとに開始する。固定の実施周期を仮定しない。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
