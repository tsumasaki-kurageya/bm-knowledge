# 空気・水などを測定し、衛生状態を確認する

## 目的

空気や水などを調べ、衛生上の問題がないか、設備の調整や対策が必要かを判断します。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-005：点検・測定](../01-domains/inspection-assessment.md)
- 関連領域：[DOMAIN-004：日々の運転・手入れ・清掃](../01-domains/operations.md)、[DOMAIN-006：異常・故障への対応](../01-domains/incident-response.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

測定・調査時期、利用者からの申告、対策後の効果確認。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：適用対象の項目・方法等を確認。
- 契約：追加測定の要件。
- 運用：異常調査・効果確認も含む。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 測定・調査担当者 | 測定・調査 | 条件をそろえた測定 |
| 専門的評価者 | 結果の評価 | 結果の判断 |
| 管理者 | 対策手配 | 対策手配 |

<a id="入力"></a>

## 必要な情報

- 対象・測定条件
- 適用基準
- 過去結果
- 利用・設備条件

## 標準フロー

概略のつながりのみを示す。対象に合う条件で測定・調査を行い、結果を評価して、対策・再測定等の必要性を渡す。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

結果を調べる機能を主とし、薬剤処理・設備調整等は実施側へ渡す。

<a id="出力"></a>

## 作業後に残すもの

- 測定・調査値と条件
- 適否・傾向の評価
- 対策・再測定の必要性

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：測定・調査時期、利用者からの申告、対策後の効果確認。 前工程の完了だけが開始条件ではない。
- 繰返し：次の合意済み実施時期・評価時期等で本業務を再開する。毎回同じ計画・発注・承認をやり直すとは限らず、条件変更がある場合に見直す。周期・期限は法令・契約・管理計画で確認する。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
