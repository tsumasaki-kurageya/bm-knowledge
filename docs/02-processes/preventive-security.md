# 巡回・入退館の確認で危険を防ぐ

## 目的

巡回や入退館の確認などを通じて、危険や不適切な利用を早く見つけ、防ぎます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-008：事故の予防・災害への備え](../01-domains/risk-preparedness.md)
- 関連領域：[DOMAIN-006：異常・故障への対応](../01-domains/incident-response.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

警戒・巡回の予定、入退館、危険情報・利用状況の変化。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：警備・安全等の適用条件を確認。
- 契約：警戒範囲・時間・権限。
- 運用：危険な利用状態への予防。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 警備・管理担当者 | 予防活動の実施 | 権限内の予防活動 |
| 施設運営者 | 利用条件の判断 | 立入・利用条件の判断 |
| 利用者 | 協力・異常連絡 | 利用条件の遵守・異常連絡 |

<a id="入力"></a>

## 必要な情報

- 警戒・利用条件
- 立入権限
- 施設情報
- 過去事象

## 標準フロー

概略のつながりのみを示す。警戒・利用条件に基づく予防活動を行い、危険・異常を連絡して、記録と必要な条件変更を残す。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

設備の技術点検は点検業務、発生事象への対応は異常対応へ渡す。

<a id="出力"></a>

## 作業後に残すもの

- 警戒・入退管理の結果
- 危険の連絡
- 予防条件の見直し事項

「関連」は情報や結果を照合する関係で、実施や承認の順番ではありません。複数の担当へ同時に引き継ぐこともあります。危険を知らせるときに、記録や報告書の完成を待つ必要はありません。

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：警戒・巡回の予定、入退館、危険情報・利用状況の変化。 前工程の完了だけが開始条件ではない。
- 繰返し：次の合意済み実施時期・評価時期等で本業務を再開する。毎回同じ計画・発注・承認をやり直すとは限らず、条件変更がある場合に見直す。周期・期限は法令・契約・管理計画で確認する。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
