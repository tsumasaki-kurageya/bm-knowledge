# 契約どおりに作業されたか確認する

約束した作業と実際の結果を比べ、終わったもの・残ったもの・契約と違うものを確認します。

## このページで扱う範囲

参照仕様の業務検査を、契約どおりに作業されたかの確認の具体例として扱う。法定検査や、工事ごとの完成検査を包含する統一手順ではない。資料に示された準備・照合・記録を詳細化し、不合格後の再検査や支払承認手続は未確認として分ける。

手順は資料をもとに読みやすく整理したものです。資料に書かれた内容と、確認が必要な点を根拠欄で区別しています。

## いつ始めるか

作業・工事の完了申告、契約上の確認時期、是正後の再確認。

変更や異常の発生から直接始まることもあり、前の業務の完了だけが開始条件ではありません。

## 法令・契約・日常管理との関係

- 法令：法定検査等と同一視しない。
- 契約：履行条件の照合が中心。
- 運用：自営作業の依頼確認にも応用可能。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## どこまでできれば完了か

依頼・契約条件との照合結果と、確認できない点・不一致を区別して引き渡せることを本書の終了判定とする。受領・支払が承認されたことや、対象設備の安全性が全面的に確認されたことまでは意味しない。資料不足で確認できない場合は、確認完了と扱わない。

根拠のある作業・報告の範囲は標準フローの各行、具体的に決められない条件は判断・例外の表に示す。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 受託者・実施者 | 結果の提示 | 結果・成果物の提示 |
| 確認者・管理者 | 契約どおりの作業かの確認 | 依頼条件との照合 |
| 発注権限者 | 受領判断 | 受領・追加対応の判断 |

## 必要な情報

- 仕様・依頼条件
- 実施報告
- 状態確認・試験結果
- 未完了事項

## 標準フロー

参照資料は[詳細フローの根拠](#詳細フローの根拠)。各行の「根拠」はその資料の編・節を示す。以下は読解上の段階であり、相互の調整や確認を必ず一度ずつ直列に実行するとの規定ではない。

| 手順・担当 | 行うこと | 得られる情報・根拠 |
| --- | --- | --- |
| C1 確認条件と資料を準備（実施者・報告担当者） | 対象の契約図書、計画・報告等の必要資料を揃える。 | 確認対象と提出資料。根拠・未確認：第1編1.6.1 |
| C2 指定された確認者が照合（発注者が指定した確認者） | 実施結果の資料を契約図書と照らして確認する。 | 適否を判断する情報。根拠・未確認：第1編1.1.2の検査の定義、1.6.1 |
| C3 結果・協議事項を引き渡す（確認者・実施者・管理者） | 確認に伴う協議と結果情報を報告・記録へつなぐ。 | 確認結果・協議記録・残課題。根拠・未確認：第1編1.2.4／結果の具体的な様式・決裁経路は未確認 |

## 判断ポイント・分岐

| 判断すること | 分岐・扱い | 根拠または確認が必要な条件 |
| --- | --- | --- |
| 必要な資料が揃っているか | C1で確認対象を整理。不足時の補足要求・確認の延期方法は契約で確認する。 | 第1編1.6.1／不足時の具体手続は未確認 |
| 確認者が誰か | 契約の指定を確認する。作業の実施者が自動的に受領・支払を判断するとはしない。 | 第1編1.6.1 |
| 依頼条件と結果が一致するか | C2で照合する。不一致や判定不能を区別するが、その後の受領可否・是正義務は契約確認が必要。 | 第1編1.1.2／不一致後の決裁は未確認 |
| 是正・再調整が必要か | [作業調整（PROCESS-007）](work-coordination.md)へ調整事項を渡す。再検査の回数や費用負担を標準手順として追加しない。 | 業務間の引継ぎについての整理案／具体的手続は未確認 |

## 分岐・例外

| 代表的な例外 | 扱い | 根拠または未確認事項 |
| --- | --- | --- |
| 期間ごとの確認と業務全体の終了が異なる | 参照仕様には支払請求に係る業務検査がある。月次確認を全契約の完了と同一視しない。 | 第1編1.1.2、1.6.1 |
| 一部の実施結果だけ提出された | 確認済み範囲と未確認範囲を区別する。部分受領できるかは未確認とする。 | 未確認：契約の部分完了・受領条件 |
| 実施内容に不一致がある | 是正・再調整の必要性を関係者へ渡す。自動的な支払拒否・追加費用承認は定めない。 | 未確認：是正・支払・費用の契約条件 |
| 検査資料に危険・不具合の記載がある | 契約どおりの作業かの確認だけで安全上の支障が解消したとは扱わない。異常の情報は報告・対応の担当者へ引き渡す。 | [未対応の指摘を追う仕事（PROCESS-022）](reporting-followup.md)への引継ぎ／緊急時の連絡権限は未確認 |

| 情報・帳票 | 使用目的 | 根拠・適用条件 |
| --- | --- | --- |
| 契約図書 | C1〜C2の照合基準 | 第1編1.6.1 |
| 業務計画書・作業計画書・業務報告書 | 予定と実施結果を確認 | 第1編1.6.1 |
| 出退勤確認簿等、仕様で求める資料 | 適用する業務の履行を確認 | 第1編1.6.1。施設警備等の条件付きであり全業務必須ではない |
| 確認結果・協議・不足事項 | C3から報告・記録へ渡す | 第1編1.2.4／具体様式・受領決裁書の要否は未確認 |

## 作業後に残すもの

- 契約どおりの作業かの確認結果
- 不足・是正依頼
- 受領した成果物・残課題

## 次の業務へ渡す情報と条件

渡す情報は、契約どおりの作業かの確認結果、不足・是正依頼、受領した成果物・残課題です。次の関係は資料を組み合わせた整理案で、担当・権限・期限は建物ごとに確認します。

複数の担当へ並行して引き継ぐ場合があります。危険の連絡は、記録や報告書の完成を待たずに行います。

### 結果を報告し、未対応のものを確認する

[PROCESS-022：結果を報告し、未対応のものを確認する](reporting-followup.md)へ引き継ぐのは、報告時期・提出要請・指摘更新が生じたときです。提出責任者が要求と内容を確認。提出済みと対策完了を区別し、指摘を追跡する。

[この業務の資料](#情報源)・[引継ぎ先の資料](reporting-followup.md#情報源)に基づく整理案。未確認：提出先・様式・期限・提出権限。報告の担当と、指摘への対応を追う担当の分担。

### 台帳・図面・作業記録を更新し、引き継ぐ

[PROCESS-021：台帳・図面・作業記録を更新し、引き継ぐ](records-handover.md)へ引き継ぐのは、成果・判断・変更情報が発生または更新されたときです。記録管理者が対象・版・未完了事項を確認。欠落は不足として残す。

[この業務の資料](#情報源)・[引継ぎ先の資料](records-handover.md#情報源)に基づく整理案。未確認：保存年限・アクセス権・版管理。所有者変更時の図書引継ぎと欠落資料の扱い。

### 作業日時・設備停止・利用者への連絡を調整する

[PROCESS-007：作業日時・設備停止・利用者への連絡を調整する](work-coordination.md)へ引き継ぐのは、依頼条件と結果に不足・不一致があるときです。確認者から是正内容を渡し、作業責任者等が条件を再調整。責任未決は未決として残す。

[この業務の資料](#情報源)・[引継ぎ先の資料](work-coordination.md#情報源)に基づく整理案。未確認：停止・再開の権限、立会いの要否、緊急時に必要な調整範囲。

## 顧客の困りごとを確認する

以下は、この業務を理解するための質問です。顧客で確認済みの課題ではありません。

確認者・受託者に、次の点を聞きます。

完了報告を受けてから確認を終えるまで、どの資料や判断が不足しますか。不一致や未完了の作業をどう追っていますか。

確認に使う情報：依頼条件、実施結果、差戻し理由。資料の作り直しと確認待ちを分ける。

## 未確認事項

- 検査・受領・支払の条件。部分完了や指摘付き受領の扱い。

- 確認が必要な点：不一致時の是正義務、再検査、部分受領、検収と支払の関係。共通仕様書だけでは確定せず、適用する契約本文で確認する。
