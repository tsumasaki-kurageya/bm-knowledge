<a id="建物内外の清掃汚れの予防"></a>

# 建物を清掃し、汚れを防ぐ

## 目的

建物の汚れを取り除き、汚れによる使いにくさや床・壁などの傷みを防ぎます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-004：日々の運転・手入れ・清掃](../01-domains/operations.md)
- 関連領域：[DOMAIN-005：点検・測定](../01-domains/inspection-assessment.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

清掃予定、汚損の発見、利用状況の変化。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：衛生上の要求の適用を確認。
- 契約：範囲・頻度・品質。
- 運用：日常・定期・臨時を含む。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 清掃担当者 | 清掃実施 | 対象に合う作業の実施 |
| 管理者・依頼者 | 依頼・結果の確認 | 範囲と結果の確認 |
| 利用者 | 利用条件の共有 | 利用条件の共有 |

<a id="入力"></a>

## 必要な情報

- 清掃対象・仕上げ
- 汚れの状態
- 要求水準
- 利用・安全条件

## 標準フロー

概略のつながりのみを示す。対象・汚れ・利用条件を確認し、清掃・汚れ予防を行って、仕上がりと残る支障を確認する。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

貯水槽等の専門的な衛生維持は衛生管理へ主に紐付け、同じ作業を二重登録しない。

<a id="出力"></a>

## 作業後に残すもの

- 清掃実施結果
- 仕上がりの確認
- 除去できない汚れ・損傷等の指摘
