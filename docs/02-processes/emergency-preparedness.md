# 非常時の連絡・対応を決めて訓練する

## 目的

非常時の連絡先・役割・対応方法を決め、訓練などで実際に対応できるか確かめます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-008：事故の予防・災害への備え](../01-domains/risk-preparedness.md)
- 関連領域：[DOMAIN-003：担当・発注・作業の調整](../01-domains/delivery-coordination.md)、[DOMAIN-006：異常・故障への対応](../01-domains/incident-response.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

管理開始、担当・建物条件変更、訓練時期、発生事象の振返り。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：対象建物の防火防災等の要件を確認。
- 契約：支援・参加範囲。
- 運用：任意の災害への備えも区別。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 権原者・施設運営者 | 方針判断 | 備えの方針 |
| 防火防災等の担当者・管理者 | 計画・周知・訓練 | 計画・周知・訓練の調整 |
| 利用者・関係機関 | 協力・助言 | 協力・助言 |

<a id="入力"></a>

## 必要な情報

- 想定危険
- 建物・利用条件
- 関係者・設備情報
- 過去の対応課題

## 標準フロー

概略のつながりのみを示す。想定危険に対する連絡・役割を整え、周知・訓練を通じて、備えの不足と見直し事項を確認する。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

建物の維持保全に関係する備えを扱い、組織全体のBCPを網羅しない。

<a id="出力"></a>

## 作業後に残すもの

- 連絡・役割・対応計画
- 周知・訓練の結果
- 備えの見直し事項

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：管理開始、担当・建物条件変更、訓練時期、発生事象の振返り。 前工程の完了だけが開始条件ではない。
- 繰返し：次の合意済み実施時期・評価時期等で本業務を再開する。毎回同じ計画・発注・承認をやり直すとは限らず、条件変更がある場合に見直す。周期・期限は法令・契約・管理計画で確認する。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
