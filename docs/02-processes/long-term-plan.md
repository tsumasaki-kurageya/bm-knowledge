# 将来の修繕と費用を計画する

## 目的

数年先の修繕や設備交換を見通し、必要な費用とお金の準備を計画します。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="詳細化の範囲"></a>

## このページで扱う範囲

官庁施設の中長期様式と、既存マンション向けの長期修繕計画の記載例から、工事候補・時期・概算・資金前提の組立てを詳しくする。マンションの積立方式・総会手続を全建物の要件とは扱わない。

手順は資料をもとに読みやすく整理したものです。資料に書かれた内容と、確認が必要な点を根拠欄で区別しています。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-002：作業・修繕・費用の計画](../01-domains/planning.md)
- 関連領域：[DOMAIN-007：修繕・更新](../01-domains/repair-renewal.md)、[DOMAIN-009：記録・報告・改善](../01-domains/records-evaluation.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

計画新設、見直し時期、劣化・利用方針・工事費等の変化。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：維持すべき状態等を前提にする。
- 契約：計画作成の委託等がある場合に適用。
- 運用：任意の将来見通しも含む。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

<a id="終了条件"></a>

## どこまでできれば完了か

将来の工事候補・時期・費用・資金前提と不確実性、合意または未決の事項を整理し、年度計画や工事案の具体化へ渡せることを本書の終了判定とする。計画は将来価格・施工内容や資金調達成功の保証ではない。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 計画支援者・管理者 | 計画・費用検討 | 対策と費用の比較 |
| 所有者・費用負担者 | 方針・資金の判断 | 方針・資金の判断 |
| 技術者 | 技術情報の提供 | 劣化と対策情報の提供 |

## 判断ポイント・分岐

| 判断すること | 分岐・扱い | 根拠または確認条件 |
| --- | --- | --- |
| 候補・周期をどう置くか | 現況・仕様・診断を用い、周期例を全建物の交換期限にしない。 | F3 PDF120ページ(4)(5) |
| 資金の前提に不確実性がある | 費用・価格等の変動前提を示す。予算不足だけで必要な安全対応の不要を結論しない。 | F3 PDF119ページ(2)／不足時の財源選択は未確認 |
| 工事実施時期が近づく | 事前の調査・診断で要否・内容を具体化する。計画への掲載だけで着工を承認しない。 | F3 PDF119ページ・計画の前提(4) |
| 状態・用途・価格等が変わる | 計画前提を見直す。変更の承認や通知の方法は個別確認する。 | F3 PDF119ページ(2)、F2本文 |

## 分岐・例外

| 代表的な例外 | 扱い | 根拠または未確認 |
| --- | --- | --- |
| 図書・数量・劣化情報が不足する | 仮定と不足を明示し、調査済みとして扱わない。 | F3の資料・診断を用いる考え方／不足時の調査範囲は未確認 |
| 計画期間外の工事がある | 期間内の計上漏れと期間外の参考情報を区別する。 | F3 PDF120ページ(4) |
| 性能向上も要望される | 必要な性能・範囲を分けて検討し、原状回復の費用と混同しない。 | F3 PDF119〜120ページ／追加投資の判断基準は未確認 |
| 複数所有者で合意できない | 案と合意済み事項を分ける。多数決や決裁者を本書で新たに定めない。 | 未確認：規約・権原・契約・意思決定条件 |

## 使用される情報・帳票

既存の入出力を具体化する。資料の様式を全建物の必須帳票にせず、保存可能な記録の内容と役割を示す。

| 情報・帳票 | 使用目的 | 根拠・適用条件 |
| --- | --- | --- |
| 図書・調査診断・修繕履歴 | 候補・仕様の根拠 | F3 PDF119〜120ページ |

| 工事項目・費用・収支の表 | 支出と資金前提を照合 | F3様式第3-1号、第4-1号。マンションの資金方式を一律適用しない |
| 合意・未決・見直し事項 | 計画案と実施判断を区別 | 既存の入出力を具体化／専用決裁様式は未確認 |

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：計画新設、見直し時期、劣化・利用方針・工事費等の変化。 前工程の完了だけが開始条件ではない。
- 繰返し：次の合意済み実施時期・評価時期等で本業務を再開する。毎回同じ計画・発注・承認をやり直すとは限らず、条件変更がある場合に見直す。周期・期限は法令・契約・管理計画で確認する。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
