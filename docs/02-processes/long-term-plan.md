# 将来の修繕と費用を計画する

数年先の修繕や設備交換を見通し、必要な費用とお金の準備を計画します。

## このページで扱う範囲

官庁施設の中長期様式と、既存マンション向けの長期修繕計画の記載例から、工事候補・時期・概算・資金前提の組立てを詳しくする。マンションの積立方式・総会手続を全建物の要件とは扱わない。

手順は資料をもとに読みやすく整理したものです。資料に書かれた内容と、確認が必要な点を根拠欄で区別しています。

## いつ始めるか

計画新設、見直し時期、劣化・利用方針・工事費等の変化。

予定に沿って繰り返す場合も、条件の変更がなければ計画・発注・承認を毎回やり直すとは限りません。周期・期限は法令・契約・管理計画で確認します。

## 法令・契約・日常管理との関係

- 法令：維持すべき状態等を前提にする。
- 契約：計画作成の委託等がある場合に適用。
- 運用：任意の将来見通しも含む。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## どこまでできれば完了か

将来の工事候補・時期・費用・資金前提と不確実性、合意または未決の事項を整理し、年度計画や工事案の具体化へ渡せることを本書の終了判定とする。計画は将来価格・施工内容や資金調達成功の保証ではない。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 計画支援者・管理者 | 計画・費用検討 | 対策と費用の比較 |
| 所有者・費用負担者 | 方針・資金の判断 | 方針・資金の判断 |
| 技術者 | 技術情報の提供 | 劣化と対策情報の提供 |

## 必要な情報

- 要求・利用予定
- 設備台帳・劣化評価
- 修繕履歴
- 概算単価・財源条件

| 手順・担当 | 行うこと | 得られる情報・根拠 |

| L2 候補と仕様・時期を置く（技術者・計画担当者） | 対象に応じた修繕・更新候補と時期の前提を整理する。 | 候補・仕様・周期の前提。根拠・未確認：F3 PDF120ページ(4)(5)、F2様式1 |
| L3 概算費用を見積もる（計画担当者・費用検討者） | 数量・単価等に基づく概算と費用の前提を整理する。 | 項目別・時期別の費用見通し。根拠・未確認：F3 PDF120ページ(6)、F2様式1 |
| L4 資金との対応を確認（費用負担者・計画支援者） | 支出の見通しと資金の前提を比較し、不確実性を明示する。 | 資金計画案・不足等の論点。根拠・未確認：F3 PDF119ページ(1)(2)、様式第4-1号／財源選定・金融判断は未確認 |
| L5 計画の合意事項を整理（所有者等・意思決定者） | 計画についての合意と未決事項を区別する。 | 合意した前提と残る論点。根拠・未確認：F3 PDF119ページ(1)／決議・承認方法は所有形態ごとに確認 |
| L6 実施前の具体化・見直しへ渡す（管理者・計画担当者） | 予定を年度計画・工事案へ渡し、状態・費用の変化で見直す。 | 次の検討対象・見直し前提。根拠・未確認：F3 PDF119ページ(2)、F2本文／年度計画への引継ぎは整理案 |

## 判断ポイント・分岐

| 判断すること | 分岐・扱い | 根拠または確認条件 |
| --- | --- | --- |
| 候補・周期をどう置くか | 現況・仕様・診断を用い、周期例を全建物の交換期限にしない。 | F3 PDF120ページ(4)(5) |
| 資金の前提に不確実性がある | 費用・価格等の変動前提を示す。予算不足だけで必要な安全対応の不要を結論しない。 | F3 PDF119ページ(2)／不足時の財源選択は未確認 |
| 工事実施時期が近づく | 事前の調査・診断で要否・内容を具体化する。計画への掲載だけで着工を承認しない。 | F3 PDF119ページ・計画の前提(4) |
| 状態・用途・価格等が変わる | 計画前提を見直す。変更の承認や通知の方法は個別確認する。 | F3 PDF119ページ(2)、F2本文 |

## 分岐・例外

| 代表的な例外 | 扱い | 根拠または未確認 |
| --- | --- | --- |
| 図書・数量・劣化情報が不足する | 仮定と不足を明示し、調査済みとして扱わない。 | F3の資料・診断を用いる考え方／不足時の調査範囲は未確認 |
| 計画期間外の工事がある | 期間内の計上漏れと期間外の参考情報を区別する。 | F3 PDF120ページ(4) |
| 性能向上も要望される | 必要な性能・範囲を分けて検討し、原状回復の費用と混同しない。 | F3 PDF119〜120ページ／追加投資の判断基準は未確認 |
| 複数所有者で合意できない | 案と合意済み事項を分ける。多数決や決裁者を本書で新たに定めない。 | 未確認：規約・権原・契約・意思決定条件 |

## 次の業務へ渡す情報と条件

渡す情報は、時期別の修繕・更新候補と費用見通し、資金計画案、前提・不確実性です。次の関係は資料を組み合わせた整理案で、担当・権限・期限は建物ごとに確認します。

複数の担当へ並行して引き継ぐ場合があります。危険の連絡は、記録や報告書の完成を待たずに行います。

### 年度・日常の作業計画を立てる

[PROCESS-003：年度・日常の作業計画を立てる](annual-plan.md)へ引き継ぐのは、次期編成または時期・配分の変更が必要なときです。費用負担者等が優先度・予算を判断。未決事項を実施確定と扱わない。

[この業務の資料](#情報源)・[引継ぎ先の資料](annual-plan.md#情報源)に基づく整理案。未確認：年度区切り・予算承認単位。緊急対策による既定計画変更の扱い。

### 修繕・交換の方法と範囲を決める

[PROCESS-017：修繕・交換の方法と範囲を決める](repair-design.md)へ引き継ぐのは、工事候補の実施時期が近づいた／再検討が必要なときです。概算を技術案の検討条件として渡す。長期計画への掲載だけで発注・着工を認めない。

[この業務の資料](#情報源)・[引継ぎ先の資料](repair-design.md#情報源)に基づく整理案。未確認：設計・許認可の要否、代替案の比較基準。小修繕で省略できる成果の範囲。

### 台帳・図面・作業記録を更新し、引き継ぐ

[PROCESS-021：台帳・図面・作業記録を更新し、引き継ぐ](records-handover.md)へ引き継ぐのは、成果・判断・変更情報が発生または更新されたときです。記録管理者が対象・版・未完了事項を確認。欠落は不足として残す。

[この業務の資料](#情報源)・[引継ぎ先の資料](records-handover.md#情報源)に基づく整理案。未確認：保存年限・アクセス権・版管理。所有者変更時の図書引継ぎと欠落資料の扱い。

## 顧客の困りごとを確認する

以下は、この業務を理解するための質問です。顧客で確認済みの課題ではありません。

所有者・計画担当者に、次の点を聞きます。

修繕候補・費用・時期のどの前提が分からず判断に困りますか。前提が変わったとき、見直しと合意にどんな手間がかかりますか。

確認に使う情報：点検結果、数量・単価の前提、計画の変更履歴。工事の見通しと発注の承認を分ける。
