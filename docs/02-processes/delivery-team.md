# 担当者・役割・必要な人員を決める

## 目的

依頼・作業・確認・判断を誰が担当するか決め、必要な人員や道具をそろえます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-003：担当・発注・作業の調整](../01-domains/delivery-coordination.md)
- 関連領域：[DOMAIN-001：守るルール・利用条件](../01-domains/requirements.md)、[DOMAIN-008：事故の予防・災害への備え](../01-domains/risk-preparedness.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

管理開始、計画・契約変更、担当者交代、必要な能力・資源の不足。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：必要な資格・選任等は個別確認。
- 契約：受託範囲・責任を整理。
- 運用：自営を含む連絡・代替体制を整備。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 管理者・発注者 | 体制調整 | 役割と体制の調整 |
| 自営担当者・受託者 | 能力・資源の提示 | 能力・資源の提示 |
| 権原者・責任者 | 権限確認 | 担当・権限の確認 |

<a id="入力"></a>

## 必要な情報

- 要求一覧
- 保全計画
- 契約範囲
- 資格・能力・資源の条件

## 標準フロー

概略のつながりのみを示す。必要な役割と能力を確認し、自営・委託を含む担い手・資源を調整して、権限と連絡関係を共有する。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

会社や部署の名前にかかわらず、誰が何を担当するかを確認します。兼務する場合もあります。

<a id="出力"></a>

## 作業後に残すもの

- 役割・権限・連絡先の整理
- 実施体制
- 不足資源と手配事項

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：管理開始、計画・契約変更、担当者交代、必要な能力・資源の不足。 前工程の完了だけが開始条件ではない。
- 変更・事象起点：対象の変更や新たな事象ごとに開始する。固定の実施周期を仮定しない。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
