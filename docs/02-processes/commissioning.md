# 依頼する作業を決めて発注する

## 目的

外部へ頼む作業の範囲や仕上がりを決め、依頼する側と受ける側の認識をそろえます。

公開資料をもとにした業務の説明です。実際の担当や手順は、建物の条件・契約によって変わります。

<a id="対象業務領域"></a>

## この業務の分類

- 主領域：[DOMAIN-003：担当・発注・作業の調整](../01-domains/delivery-coordination.md)
- 関連領域：[DOMAIN-002：作業・修繕・費用の計画](../01-domains/planning.md)、[DOMAIN-007：修繕・更新](../01-domains/repair-renewal.md)

メニューでは「主領域」の分類から探せます。「関連領域」は、この業務と関わりのある分類です。

<a id="開始条件"></a>

## いつ始めるか

外部委託の決定、契約更新、追加作業・仕様変更の必要。

<a id="業務の性質適用条件"></a>

## 法令・契約・日常管理との関係

- 法令：調達・資格等の要件は適用時に確認。
- 契約：この業務の直接の成果。
- 運用：自営のみなら発注部分は該当しない。

一つの仕事に、法令・契約・日常管理の条件が重なることがあります。具体的な義務者・周期・資格・権限は建物・設備・契約の条件から確認する。

## 関係者・役割

担当者の例を示します。一人が複数の役割を持つ場合も、分担する場合もあります。責任や承認できる範囲は、法令・契約・建物の管理ルールで確認します。

| 担当者の例 | 役割 | 責任・判断 |
| --- | --- | --- |
| 発注者・管理者 | 仕様整理 | 範囲・仕様の整理 |
| 候補受託者・専門家 | 提案・見積り | 見積り・技術条件の提示 |
| 契約権限者 | 契約判断 | 相手先・契約条件の判断 |

<a id="入力"></a>

## 必要な情報

- 計画・要求
- 対象一覧
- 実施条件
- 予算
- 提案・見積り

## 標準フロー

概略のつながりのみを示す。依頼する範囲・品質・成果物を整理し、見積り等と照合して、権限者の判断を経た契約条件へまとめる。

ここでは仕事の大まかな流れを示します。細かい手順や例外への対応は未確認です。

## 分岐・例外

入札方式・契約様式を一律に指定しない。工事案の技術的な具体化は別業務。

<a id="出力"></a>

## 作業後に残すもの

- 仕様・成果物・責任範囲を明らかにした依頼・契約
- 除外事項
- 確認条件

<a id="外部起点と繰返し"></a>

## 外からの連絡・変更と繰り返し

- 外部からも開始する条件：外部委託の決定、契約更新、追加作業・仕様変更の必要。 前工程の完了だけが開始条件ではない。
- 変更・事象起点：対象の変更や新たな事象ごとに開始する。固定の実施周期を仮定しない。
- 全体との関係：[PROCESS-024：業務のつながり](lifecycle.md)。具体的な周期、緊急度、判断権限の未確定点は本書の未確認事項に従う。
