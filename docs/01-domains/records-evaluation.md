# 記録・報告・改善

作業の記録を残して関係者へ伝え、結果を振り返って次の計画に生かす仕事です。

## 目指す状態

管理者や次の担当者が、現在の状態・判断理由・残る問題を把握し、所有者と次の対応や計画を相談できる状態を目指します。

## 防ぎたい問題

以下は業務の目的から整理したリスクです。顧客での発生状況は、個別業務の確認ポイントを使って確かめます。

履歴が散逸すること、報告書があるだけで未対応が残ること、担当交代で判断が途切れること。

## 扱う仕事・他の業務との違い

台帳・図書・実施履歴・報告・引継ぎと全体評価を横断的に扱う。現場で記録を作る行為は各実施領域にも属する。個々の設備状態の技術評価は点検領域、改善の予算・時期の決定は計画領域が担う。

## 含まれる主要業務

- 対象と版を識別できる図書・台帳・実施履歴を管理する。
- 要求に応じた報告・提出と、未対応事項の追跡・引継ぎを行う。
- 要求・状態・実施結果・費用等を照合し、保全全体の不足と改善候補を整理する。
- 要求・計画・実施体制へ見直し事項を返す。

## 関わる人

担当者の例を示します。会社の種類だけで役割が決まるわけではなく、一人が複数の役割を持つこともあります。[関わる人と建物ごとの違い（BUSINESS-002）](../00-business/actors.md)も参照。

| 担当者の例 | 役割・関与 |
| --- | --- |
| 各実施者・専門家 | 観測・作業・判断根拠と未確認事項を記録する。 |
| 管理者・情報管理担当者 | 情報の集約・更新・報告・引継ぎを調整する。 |
| 所有者・承認者・報告先 | 結果と残課題を確認し、方針変更に使う。提出先は要求により異なる。 |

## 未確認事項

- 記録の保存年限・提出先・閲覧権限は法令と契約で確認する。
- 全体評価の指標・頻度、報告受領後の未対応追跡は、個別の業務と現場の記録で検証する。
