# 記録・報告・保全評価

## 概要

状態・実施・判断の情報を引き継げる形に保ち、保全全体の結果を次の要求・計画へ戻す領域。

[DOMAIN-000：業務領域一覧](overview.md)の初期分類。以下の目的・境界・業務例・関係は、末尾の資料を踏まえた本知識ベースの整理案であり、公式分類や現場で確認した実態ではない。

## 目的

管理の継続性と法令等への適合を支え、7つの目的に照らして保全を見直せる状態にする。 [BUSINESS-001：建物維持保全の全体像](../00-business/overview.md)の目的に対応する。

## 解決する問題

履歴が散逸すること、報告書があるだけで未対応が残ること、担当交代で判断が途切れること。

## 対象範囲・境界

台帳・図書・実施履歴・報告・引継ぎと全体評価を横断的に扱う。現場で記録を作る行為は各実施領域にも属する。個々の設備状態の技術評価は点検領域、改善の予算・時期の決定は計画領域が担う。

## 含まれる主要業務

- 対象と版を識別できる図書・台帳・実施履歴を管理する。
- 要求に応じた報告・提出と、未対応事項の追跡・引継ぎを行う。
- 要求・状態・実施結果・費用等を照合し、保全全体の不足と改善候補を整理する。
- 要求・計画・実施体制へ見直し事項を返す。

## 関係主体

役割の例であり、特定の会社種別への固定的な割当ではない。同じ主体が複数の役割を担う場合がある。[BUSINESS-002](../00-business/actors.md)も参照。

| 主体 | 役割・関与 |
| --- | --- |
| 各実施者・専門家 | 観測・作業・判断根拠と未確認事項を記録する。 |
| 管理者・情報管理担当者 | 情報の集約・更新・報告・引継ぎを調整する。 |
| 所有者・承認者・報告先 | 結果と残課題を確認し、方針変更に使う。提出先は要求により異なる。 |
