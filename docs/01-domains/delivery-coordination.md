# 担当・発注・作業の調整

担当者や依頼先を決め、作業するための準備・発注・調整と、契約どおりの作業かの確認を行う仕事です。

## 目指す状態

依頼する側と作業する側が、範囲・日時・担当・完了の条件を共有し、必要な作業を実施・確認できる状態を目指します。

## 防ぎたい問題

以下は業務の目的から整理したリスクです。顧客での発生状況は、個別業務の確認ポイントを使って確かめます。

依頼範囲の不一致、必要な資格・資機材の不足、複数業者の作業衝突、実施結果の確認漏れ。

## 扱う仕事・他の業務との違い

自営・委託の双方を対象とする。委託の場合に仕様・調達・契約・契約どおりの作業かの確認を含む。所有者、管理者、受託者の組織そのものを領域にはしない。予算方針は計画、設備状態の技術評価は点検領域が扱う。

## 含まれる主要業務

- 実施・依頼・承認・確認の役割、必要な能力と資源を定める。
- 委託範囲・成果物・連絡方法を明らかにし、発注条件を調整する。
- 作業日程、入退館、停止、作業安全、利用者への周知を関係者間で調整する。
- 契約・依頼条件と実施結果を照合し、未完了事項を引き継ぐ。

## 関わる人

担当者の例を示します。会社の種類だけで役割が決まるわけではなく、一人が複数の役割を持つこともあります。[関わる人と建物ごとの違い（BUSINESS-002）](../00-business/actors.md)も参照。

| 担当者の例 | 役割・関与 |
| --- | --- |
| 発注者・所有者・管理者 | 実施条件の決定、依頼、契約どおりの作業かの確認。 |
| 自営担当者・受託者・専門業者 | 能力・資源・作業条件の提示と実施調整。 |
| 利用者・施設運営者 | 入室・停止・周知等の利用条件の調整。 |

## 未確認事項

- 資格・再委託・検査・支払等の具体条件は契約と法令ごとに確認する。
- 計画を決める人と、発注・作業の調整をする人の分担は、契約と現場の記録で確認する。
