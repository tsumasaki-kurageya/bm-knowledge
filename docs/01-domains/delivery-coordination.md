# 業務実施体制・発注調整

## 概要

決めた保全を実行できるよう、役割・資源・作業条件と委託時の契約条件を整える領域。

[DOMAIN-000：業務領域一覧](overview.md)の初期分類。以下の目的・境界・業務例・関係は、末尾の資料を踏まえた本知識ベースの整理案であり、公式分類や現場で確認した実態ではない。

## 目的

経済性・実行可能性と管理の継続性を支え、責任や作業の抜けを減らす。 [BUSINESS-001：建物維持保全の全体像](../00-business/overview.md)の目的に対応する。

## 解決する問題

依頼範囲の不一致、必要な資格・資機材の不足、複数業者の作業衝突、実施結果の確認漏れ。

## 対象範囲・境界

自営・委託の双方を対象とする。委託の場合に仕様・調達・契約・履行確認を含む。所有者、管理者、受託者の組織そのものを領域にはしない。予算方針は計画、設備状態の技術評価は点検領域が扱う。

## 含まれる主要業務

- 実施・依頼・承認・確認の役割、必要な能力と資源を定める。
- 委託範囲・成果物・連絡方法を明らかにし、発注条件を調整する。
- 作業日程、入退館、停止、作業安全、利用者への周知を関係者間で調整する。
- 契約・依頼条件と実施結果を照合し、未完了事項を引き継ぐ。

## 関係主体

役割の例であり、特定の会社種別への固定的な割当ではない。同じ主体が複数の役割を担う場合がある。[BUSINESS-002](../00-business/actors.md)も参照。

| 主体 | 役割・関与 |
| --- | --- |
| 発注者・所有者・管理者 | 実施条件の決定、依頼、履行確認。 |
| 自営担当者・受託者・専門業者 | 能力・資源・作業条件の提示と実施調整。 |
| 利用者・施設運営者 | 入室・停止・周知等の利用条件の調整。 |

## 未確認事項

- 資格・再委託・検査・支払等の具体条件は契約と法令ごとに確認する。
- 計画との境界は、Issue4で発注候補を整理し、同じプロセスを重複登録しないよう検証する。
