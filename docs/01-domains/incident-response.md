# 異常・故障への対応

## 概要

異常の連絡を受け、被害を広げないための対応と復旧を進める仕事です。

公開資料をもとに仕事を分類しています。法令で定められた分類ではありません。

## 目的

人の安全と機能継続を主に支え、衛生被害や資産への損傷の拡大を抑える。 [BUSINESS-001：建物維持保全の全体像](../00-business/overview.md)の目的に対応する。

## 解決する問題

連絡が届かない、対応判断が遅れる、応急処置の後に恒久対策が抜けること。

<a id="対象範囲境界"></a>

## 扱う仕事・他の業務との違い

故障・漏水・衛生異常・災害被害・侵入等の建物への支障を扱う。非緊急の不具合も含む。事前の備えは危険予防、修理工事自体は修繕・更新へつなぐ。医療・消防・警察の専門活動や事業全体の継続計画を包含する領域ではない。

## 含まれる主要業務

- 通報・警報・点検指摘を受け付け、場所・状態・影響と未確認情報を整理する。
- 緊急度と権限に応じ、専門機関への連絡、使用制限、応急措置等を調整する。
- 復旧に必要な調査・修理を依頼し、再開条件と残る制約を関係者で確認する。
- 対応履歴と未完了の恒久対策を引き継ぐ。

<a id="関係主体"></a>

## 関わる人

担当者の例を示します。会社の種類だけで役割が決まるわけではなく、一人が複数の役割を持つこともあります。[BUSINESS-002](../00-business/actors.md)も参照。

| 担当者の例 | 役割・関与 |
| --- | --- |
| 発見者・利用者・監視担当者 | 異常の連絡と状況の提供。 |
| 管理者・権限を持つ判断者 | 優先度・使用制限・専門支援・再開条件の判断。 |
| 設備等の専門業者・関係機関 | 権限・専門性に応じた調査、応急・復旧支援。 |

## 未確認事項

- 緊急度、許容停止時間、応急対応の権限・連絡先は建物ごとの取り決めを確認する。
- 事故・苦情・単なる依頼の受付を同一プロセスにするかは、個別の業務で判断と成果を比較する。
