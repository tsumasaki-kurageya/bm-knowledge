# 事故の予防・災害への備え

事故や災害の危険を減らし、起きたときに対応できるように準備する仕事です。

## 目指す状態

管理者・利用者が危険を減らし、非常時に連絡先や役割を確認して対応できる状態を目指します。

## 防ぎたい問題

以下は業務の目的から整理したリスクです。顧客での発生状況は、個別業務の確認ポイントを使って確かめます。

危険な利用状態の見過ごし、侵入等への警戒不足、非常時の連絡・役割・対応方法が機能しないこと。

## 扱う仕事・他の業務との違い

警戒・入退管理・危険箇所管理などの予防活動と、防火・防災等の備えを対象とする。設備の点検・修繕はそれぞれの領域へ、発生した事象への対応は異常・故障への対応へつなぐ。警備会社のサービス全部や企業の事業継続計画（BCP）全体を対象にしない。

## 含まれる主要業務

- 想定する危険と利用条件を整理し、予防措置・立入条件等を調整する。
- 警戒・入退管理等を実施し、避難や安全上の支障を連絡する。
- 非常時の連絡・役割・対応方法を整え、訓練・見直しにつなぐ。

## 関わる人

担当者の例を示します。会社の種類だけで役割が決まるわけではなく、一人が複数の役割を持つこともあります。[関わる人と建物ごとの違い（BUSINESS-002）](../00-business/actors.md)も参照。

| 担当者の例 | 役割・関与 |
| --- | --- |
| 所有者・管理権原者・施設運営者 | 危険への備えと利用条件の決定。 |
| 管理者・警備担当者・防火防災の担当者 | 専門性・制度・契約に応じた予防と備え。 |
| 利用者・関係機関 | 周知・訓練・連絡体制への参加や助言。 |
