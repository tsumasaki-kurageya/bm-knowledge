# 作業・修繕・費用の計画

## 概要

必要な作業や修繕をいつ行うか、いくらかかるか、お金をどう準備するかを計画する仕事です。

公開資料をもとに仕事を分類しています。法令で定められた分類ではありません。

## 目的

資産保全と経済性・実行可能性を主に支え、安全・機能上の要求を将来まで維持する。 [BUSINESS-001：建物維持保全の全体像](../00-business/overview.md)の目的に対応する。

## 解決する問題

場当たり的な対応による対策の先送り、修繕時期の集中、資金不足、利用予定との衝突。

<a id="対象範囲境界"></a>

## 扱う仕事・他の業務との違い

日常・年度の計画と中長期の修繕・更新・資金見通しを接続する。作業員の配置・個別発注は実施体制、工事の具体化と施工は修繕・更新へ渡す。収益事業や金融商品運用そのものは扱わない。

## 含まれる主要業務

- 状態・要求・利用予定から必要な対策候補と優先度を整理する。
- 実施時期、概算費用、停止影響、財源・負担方法を比較し、計画を合意する。
- 実績・劣化・価格・用途の変化に応じて短期と中長期の計画を更新する。

<a id="関係主体"></a>

## 関わる人

担当者の例を示します。会社の種類だけで役割が決まるわけではなく、一人が複数の役割を持つこともあります。[BUSINESS-002](../00-business/actors.md)も参照。

| 担当者の例 | 役割・関与 |
| --- | --- |
| 所有者・費用負担者・意思決定機関 | 方針、予算、負担方法の判断。合意方法は所有形態による。 |
| 管理者・計画支援者 | 状態と費用情報の集約、案の比較。 |
| 点検者・設計者・施工者・利用者 | 技術条件、概算、停止可能時期などの提示。 |
